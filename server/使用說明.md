# 用自己的電腦當後端伺服器

網頁照樣放在 GitHub（網址不變），只有「線上人數、路況回報」這些後端功能跑在這台電腦上，資料也存在這台電腦。
電腦關機或睡眠時，地圖、導航、測速照相、全家／中油等都照常可用，只有後端功能會暫停。

## 第一次設定（只要做一次）

1. **安裝 Node.js**
   到 https://nodejs.org 下載 LTS 版本安裝，或在命令列執行：
   ```
   winget install OpenJS.NodeJS.LTS
   ```

2. **安裝 Tailscale 並登入**
   到 https://tailscale.com/download 下載安裝，用自己的帳號登入。

3. **開啟 Funnel（讓手機透過 HTTPS 連進來）**
   用系統管理員開命令列，執行：
   ```
   tailscale funnel --bg 8787
   ```
   第一次執行會跳出網頁要你在 Tailscale 後台允許 Funnel，照著按允許即可。
   完成後會顯示一個網址，例如 `https://my-pc.tail1234.ts.net`，這個網址固定不變。

4. **把網址填進網頁**
   打開 `智行地圖.html`，搜尋 `SNM_SERVER_URL`，把網址填進去：
   ```js
   var SNM_SERVER_URL = 'https://my-pc.tail1234.ts.net';
   ```
   推上 GitHub 後，手機開原本的 GitHub 網址就會連到這台電腦。

## 每次使用

雙擊 `server\啟動伺服器.bat`。視窗要一直開著；伺服器意外停止會在 5 秒後自動重開。

確認有沒有在運作：用瀏覽器開 `https://你的網址/api/health`，看到 `"ok":true` 就是正常。

## 資料放在哪

`C:\SmartNavData\store.json`（要換位置就改 `啟動伺服器.bat` 裡的 `SNM_DATA_DIR`）。
請不要放在 OneDrive 裡，資料每幾秒寫一次，會一直觸發同步。建議定期備份這個資料夾。

## 注意

- 電腦設定成「不要自動睡眠」（設定 → 系統 → 電源），不然睡著時後端會停。
- 捷運資料（TDX）需要金鑰時，把 `.env.example` 複製成 `.env` 填入，伺服器會自動讀取。
